项目介绍

项目简介

AgentKit 是一个跨平台桌面应用（React 19 + Rust Tauri），统一管理 AI Agent Skills，并将它们一键同步到 44 款 AI 编程工具，实现「一次安装，处处同步」。

为什么选择它

相比手动在每个工具里复制、维护同一份 Skill，AgentKit 让技能只存一份，却在每个需要它的地方保持就绪。

  • 一次安装：本地优先，无需账户，也没有云端依赖
  • 处处同步：一键同步到 44 款 AI 编程工具
  • 智能同步：symlink/junction 优先，失败自动回退 copy
  • 跨平台：支持 Windows / macOS / Linux

核心特性

一处管理

在统一视图中浏览、导入、整理所有 Agent Skills，并通过 symlink/junction 优先的同步机制保持处处就绪。

智能同步

工具感知

适用场景

  • 场景一：统一管理分散在多个 AI 工具中的 Skills
  • 场景二：需要跨工具复用同一套 Skills 的团队
  • 场景三：希望本地化管理 AI 能力的个人开发者

技术栈

前端使用 React 19 + TypeScript 5.9 + Vite 7 + Tailwind CSS 4，后端使用 Rust + Tauri 2，数据库使用 SQLite（rusqlite）。

提示： 本项目完全开源，你可以在 GitHub 上查看完整源代码并自行构建。

环境要求

  • Node.js 18+（推荐 20+） / Rust 1.77+

运行第一个示例

shell
复制
