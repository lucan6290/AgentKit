项目介绍

项目简介

AgentKit 是一个跨平台桌面应用（React 19 + Rust Tauri），统一管理 AI Agent Skills，并将它们一键同步到 44 款 AI 编程工具的全局或项目级 skills 目录，实现「一次安装，处处同步」。

为什么选择它

相比手动在每个工具里复制、维护同一份 Skill，AgentKit 让技能只存一份，却在每个需要它的地方保持就绪。

  • 一次安装：本地优先，无需账户，也没有云端依赖
  • 处处同步：一键同步到 44 款 AI 编程工具
  • 智能同步：symlink/junction 优先，失败自动回退 copy
  • 跨平台：支持 Windows / macOS / Linux

核心特性

  • 一处管理：在统一视图中浏览、导入、整理所有 Agent Skills
  • 全局 / 项目级同步：同步到全局目录或限定到指定项目目录
  • 标签与筛选：为 Skill 添加多个标签，按标签快速定位
  • 技能详情：Markdown 渲染与代码语法高亮（40+ 语言）

技术栈

  • 前端：React 19 + TypeScript 5.9 + Vite 7 + Tailwind CSS 4
  • 后端：Rust + Tauri 2 + SQLite（rusqlite）
  • 国际化：i18next（中英双语）
提示： 本项目完全开源（MIT License），你可以在 GitHub 上查看完整源代码并自行构建。

安装

根据你的操作系统，选择下载安装包或从源码构建。

下载安装包

前往 下载页面 或 GitHub Releases 获取对应平台的安装包：

  • Windows：NSIS 安装包（.exe）
  • macOS：.dmg 镜像
  • Linux：AppImage

从源码构建

shell
复制 
# 克隆仓库
$ git clone https://github.com/lucan6290/agentkit.git

# 进入前端目录并安装依赖
$ cd agentkit/frontend
$ npm install

# 构建生产版本（输出 NSIS 安装包）
$ npm run tauri build

构建产物输出到 src-tauri/target/release/bundle/ 目录。

快速开始

在本地跑起开发环境，体验完整功能。

环境要求

  • Node.js 18+（推荐 20+）
  • Rust 1.77+（stable）
  • Tauri Prerequisites

启动开发模式

shell
复制 
# 进入前端目录
$ cd frontend

# 安装依赖
$ npm install

# 启动开发模式（Vite + Tauri）
$ npm run tauri dev

npm run tauri dev 会同时启动 Vite 开发服务器（http://127.0.0.1:5173）和 Tauri 桌面窗口，并监听 Rust 代码变更热重载。

质量检查

shell
复制 
# 前端 lint + build
$ npm run check

# Rust 测试
$ cd src-tauri && cargo test

3.2

同步机制

同步模式

AgentKit 同步 Skill 时优先使用链接，失败时自动回退为复制：

  • symlink / junction：优先使用，不占用额外磁盘空间，改动实时生效
  • copy：当链接不可用（如 Windows 权限受限）时回退为目录复制

同步范围

范围说明
全局同步到工具全局 skills 目录，在所有项目中生效
项目级同步到指定项目目录（如 <project>/.claude/skills），仅在该项目生效

无论哪种范围，Skill 都只在 Community Repo 中存储一次，同步目标只是链接或副本。你可以在「同步范围控制」中切换 Skill 的全局 / 项目范围，并管理项目目录。

提示： 同步到 Cursor 时始终使用复制，因为 Cursor 暂不支持基于 symlink/junction 的 skills 目录。

标签与筛选

标签管理

在独立的 Tags 标签页中新建、重命名、删除自定义标签，并可快速跳转到对应的 Skill 列表。

标签筛选

  • 为 Skill 添加多个标签
  • 在 My Skills 中按标签筛选
  • 支持查看「无标签」Skill
提示： 标签只是帮助你查找和组织 Skill，不会改变 Skill 的同步位置或可用工具。

版本与发布

版本管理

前后端版本号通过 scripts/version.mjs 统一管理，请勿手动单独修改。

shell
复制 
# 校验前后端版本一致
$ node scripts/version.mjs check

# 设置新版本号（同时更新 package.json 和 Cargo.toml）
$ node scripts/version.mjs set 0.x.x

版本号来源：前端 frontend/package.json，后端 frontend/src-tauri/Cargo.toml。

发布流程

  • 先更新 CHANGELOG.md，在「Unreleased」下方添加新版本条目
  • 运行 node scripts/version.mjs set 0.x.x 更新版本号
  • 提交并打 tag：git tag -a v0.x.x
  • 推送 tag 后，GitHub Actions 自动构建 NSIS 与 MSI 安装包并创建 draft Release

常见问题

Skills 存储在哪里？

Community Repo 默认位于 ~/.agentkit/skills/community-skills（可在设置中修改）。

标签有什么用？

标签帮助你查找和组织 skills，不会改变 skill 同步的位置或哪些工具可以使用它。

什么是项目级同步？

Skill 仍然只在 Community Repo 中存储一次，但其同步目标是某个选定的项目目录，例如 <project>/.agents/skills、<project>/.claude/skills 或其他工具特定的项目 skills 路径。

为什么同步到 Cursor 总是使用 copy？

Cursor 目前不支持基于 symlink/junction 的 skills 目录，因此 AgentKit 在同步到 Cursor 时强制使用目录复制。

为什么同步有时会回退到 copy？

AgentKit 优先使用 symlink/junction，但在某些系统上（尤其是 Windows）symlink 可能受限，此时回退为目录复制。

遇到问题时日志在哪里？

日志文件位于 ~/.agentkit/data/logs/ 目录，遇到问题时先查看详细错误信息。
