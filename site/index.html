核心能力

让技能管理，变得自然简单

不用再为每个工具复制、维护同一份 Skill。AgentKit 让技能只存一份，却在每个需要它的地方保持就绪。

一处管理

在统一视图中浏览、导入、查看和整理所有 Agent Skills。标签与详情让每一个能力都清晰可见。

  • 统一技能视图
  • 标签与详情
  • 从本地或工具导入
  • 快速搜索与筛选

智能同步

优先使用 symlink 或 junction；受限时自动回退复制。全局或项目级范围，由你决定。

  • symlink / junction 优先
  • 自动回退 copy
  • 全局或项目级范围
  • 多工具目标目录

工具感知

自动识别已安装的 AI 工具，展示每个 Skill 的生效状态，并让新增工具快速接入。

  • 自动识别 44 款工具
  • 生效状态一目了然
  • 新工具快速接入
  • 统一工具适配层

工作流

从收藏到每次对话，始终只有三步。

AgentKit 不改变你的工具习惯，只替你消除分散的目录、重复的拷贝与难以追踪的版本。

1

导入技能

从本地文件夹或已有工具中迁移，保留你已经积累的提示与工作流。

2

选择范围

将 Skill 设为全局可用，或仅同步到特定项目，保持上下文干净。

3

专注创造

打开任意支持的 AI 工具，所需 Skill 已在正确的位置等待使用。
