初级 5 分钟

5分钟快速上手

从安装到首次同步，5 分钟内完成 AgentKit 初始化并导入第一个 Skill。

点击展开
1安装 AgentKit
使用包管理器一键安装AgentKit。
bash复制
# 下载安装包
$ https://github.com/lucan6290/agentkit/releases/latest
✓ 安装完成 · 版本 v0.3.1
2首次启动
启动 AgentKit 并完成 Onboarding 引导，扫描已安装的 AI 工具。
bash复制
# 启动 AgentKit
$ agentkit run
→ 初始化本地存储 ~/.agentkit/data.db
✓ AgentKit 已启动 · 桌面窗口
3导入第一个 Skill
从本地文件夹或已有工具导入 Skill，查看同步结果。
bash复制
# 导入并同步 Skill
$ 导入 frontend-design → Cursor
✓ Skill 已导入
✓ 已同步到 3 款工具
初级 10 分钟

导入你的第一个 Skill

从本地文件夹或已有 AI 工具导入 Skill，快速建立你的技能库。

点击展开
1选择导入来源
支持本地文件夹多选、.claude/skills 目录，以及从已安装工具迁移。
json复制
# tasks.json — 任务配置文件
{
  "name": "启动开发环境",
  "command": "npm run dev",
  "cwd": "~/projects/my-app",
  "env": { "PORT": "3000" },
  "retry": 3,
  "timeout": 30000
}
2导入并同步
导入后选择目标工具与范围，一键同步到对应 skills 目录。
bash复制
# 加载并运行任务
$ agentkit task load ./tasks.json
→ 加载任务: 启动开发环境
$ agentkit task run
✓ VITE v5.4.8 ready in 412ms
✓ Local: http://localhost:3000/
中级 15 分钟

配置同步范围

全局或项目级同步，优先 symlink/junction，受限时自动回退 copy。

点击展开
1全局同步
将 Skill 同步到全局目录，在所有项目中生效。
bash复制
# deploy.sh — 参数化部署脚本
#!/bin/bash
TARGET="${1:-production}"
BRANCH="${2:-main}"

echo "部署分支 $BRANCH 到 $TARGET"
git checkout $BRANCH
npm run build
rsync -avz dist/ $TARGET:/var/www/app/
echo "✓ 部署完成"
2项目级同步
限定到特定项目目录，保持上下文干净。
bash复制
# 带错误处理的构建脚本
set -e

if ! npm run lint; then
  echo "✗ 代码检查失败"
  exit 1
fi

npm run build
echo "✓ 构建成功"
中级 20 分钟

管理标签与筛选

为 Skill 添加多个标签，按标签快速筛选与组织。

点击展开
1创建标签
在标签页新建、重命名、删除自定义标签。
json复制
# workflow.json — 自动化工作流
{
  "name": "CI/CD 流水线",
  "steps": [
    { "name": "安装依赖", "cmd": "npm ci" },
    { "name": "代码检查", "cmd": "npm run lint" },
    { "name": "单元测试", "cmd": "npm test" },
    { "name": "构建", "cmd": "npm run build" },
    { "name": "部署", "cmd": "./deploy.sh" }
  ],
  "on_fail": "stop",
  "parallel": false
}
2按标签筛选
在 My Skills 中按标签筛选，包括查看「无标签」Skill。
bash复制
# 运行工作流
$ agentkit workflow run ./workflow.json
→ [1/5] 安装依赖 ✓
→ [2/5] 代码检查 ✓
→ [3/5] 单元测试 ✓ 42 passed
→ [4/5] 构建 ✓ 4.2s
→ [5/5] 部署 ✓
✓ 工作流完成 · 总耗时 38s

数据存储与迁移

了解 AgentKit 的数据目录结构，完成备份与跨设备迁移。

点击展开
1数据目录
Skills 存储在 ~/.agentkit 下，按资源类型分目录管理。
bash复制
# 创建完整备份
$ agentkit backup create
→ 导出配置文件 ~/.agentkit/config.json
→ 导出数据库 ~/.agentkit/data.db
→ 压缩加密 backup-20260912.enc
✓ 备份完成 · 大小 2.4MB
2备份数据
复制 ~/.agentkit 目录即可完成备份与跨设备迁移。
bash复制
# 从备份恢复
$ agentkit backup restore backup-20260912.enc
→ 解密备份文件
→ 恢复配置文件
→ 恢复数据库
✓ 恢复完成 · 128 个任务已恢复
3恢复数据
将备份目录放回原位置，AgentKit 会自动识别已有 Skills。
bash复制
# 添加每日凌晨3点自动备份
$ crontab -e
# 添加以下内容
0 3 * * * agentkit backup create --auto
# 保留最近 7 天备份
0 3 * * * agentkit backup prune --keep 7
